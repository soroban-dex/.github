# Soroban DEX

**Open-source developer tooling and reliability infrastructure for Soroban.**

Soroban DEX builds tools that help developers test, validate, and improve the reliability of applications built on the Stellar ecosystem.

## Projects

### [Sodex](https://github.com/soroban-dex/sodex)

A TypeScript toolkit for testing the correctness, consistency, and recovery behavior of Soroban event indexers.

Sodex helps developers validate indexer behavior using adapters, fixtures, conformance tests, and actionable reports.

## Our Focus

- Developer tooling for Soroban and Stellar
- Reliable event indexing and data consistency
- Conformance testing and regression prevention
- Clear documentation and reproducible test results
- Open-source collaboration
